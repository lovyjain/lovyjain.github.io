# JainKwiz 🚀

A modern, gamified learning platform designed to make Jain philosophy accessible, engaging, and interactive.

---

## 🌍 Problem

Traditional learning methods for Jain philosophy often lack engagement, accessibility, and scalability — especially for younger audiences and global communities.

---

## 💡 Solution

JainKwiz transforms learning into an interactive experience using gamification, real-time quizzes, and AI-powered assistance.

---

## ⚙️ Key Features

- 🎯 Real-time multiplayer quiz tournaments  
- 📊 Leaderboards (Global / Weekly / Friends)  
- 🔥 Daily streaks & spaced repetition  
- 🧠 AI chatbot for answering queries  
- 📅 Jain festival calendar & glossary  
- 📱 Progressive Web App (mobile-friendly)

---

## 🧱 Architecture

- **Frontend**: React + Ionic  
- **Backend**: Node.js APIs  
- **Hosting**: Azure Static Web Apps  
- **Database**: Cosmos DB  
- **Real-time**: Azure SignalR  
- **AI**: Azure OpenAI (planned/partial integration)

---

## ⚡ Technical Highlights

- Real-time event-driven architecture using SignalR  
- Scalable NoSQL data model using Cosmos DB  
- Gamification engine with XP, levels, and streak logic  
- Cost-optimized cloud architecture leveraging Azure free tiers  

---

## 📈 Impact

- Built as a full-stack product from scratch  
- Designed for global Jain community and Pathshala ecosystem  
- Demonstrates real-world application of enterprise architecture patterns
