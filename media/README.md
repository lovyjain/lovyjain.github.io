# Media Directory

This directory contains media files (images, videos) for blog posts and other content.

## Structure

Each blog post should have a corresponding subdirectory for its media files, named after the post date and slug.

For example:
- `/media/2026-04-10-my-first-post/`
- `/media/2026-04-12-another-post/`

### Organizing Media

Keep your media organized:
- `images/` - Featured images, screenshots, diagrams
- `videos/` - Video files (use sparingly)

This helps manage and maintain media assets alongside your content.
